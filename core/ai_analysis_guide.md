### 💡 給 AI 的分析指南與策略前提

#### 一、核心策略前提

1. **長線策略**
   * 投資策略為長線持有、只加不減。請不要建議賣出。
   * 若標的風險偏高、估值偏貴或短線過熱，請以「觀望」、「暫停加碼」、「降低加碼優先度」或「等待回測」表達。
   * 請不要推薦新標的，只針對目前持有標的進行分析。

2. **資產配置目標**
   * 區域配置目標：台股 35%、日股 30%、美股 35%。
   * 台股內部：主動型 / 被動型 = 1 : 1。
   * 若某區域或類型已明顯超配，請降低該標的的加碼優先順序。

3. **帳戶與資金限制**
   * 日幣與台幣為分別帳戶，資金互不影響。日股加碼用日幣帳戶；台股加碼用台幣帳戶；基金皆為定期定額。
   * 野村中小基金為儲蓄險附加、獨立帳戶，已持有約 20 年，請勿與短線 ETF 操作混為一談。

4. **操作紀律**
   * 若價格高於日常掛單線，不得判定為適合加碼。
   * 請區分「日常加碼」、「回測加碼」、「狙擊加碼」與「觀望」。
   * 若標的短線強勢但尚未回測，請標記 FOMO / 追價風險。
   * 請以「幾發子彈」表達加碼強度。

#### 二、Smart Benchmarks 與 RS / Alpha 解讀

本報表採用「區域自動對標」：台股 → 0050.TW、美股/全球 → VOO/S&P500、日股 → 1306.T/TOPIX。

**RS 解讀：**
* **指數型 ETF**：低 RS 不一定弱勢，可能代表跨市場再平衡的潛在買點，請結合配置目標與掛單位階判斷。
* **個股與主動型 ETF**：高 RS 代表相對大盤有動能優勢；若同時估值過高或短線過熱，請標記追價風險；若高 RS 且仍接近合理掛單位階，可列為較佳加碼候選。

**Alpha 解讀：**
* Alpha 反映相對於自身市場的超額報酬能力，可用於判斷主動型 ETF / 基金是否真正創造超額報酬。
* Alpha 正且穩定 → 提高長線持有信心。
* Alpha 轉弱或長期落後基準 → 降低加碼優先度，不要建議賣出。

---

#### 三、基本面、PEG 與掛單位階

* 接近日常線 + PEG 合理 → 日常加碼候選。
* 接近回測線 + 基本面未惡化 → 回測加碼候選。
* 接近狙擊線 + PEG < 1 → 安全邊際高，高優先加碼候選。
* 價格明顯高於日常線 → 標記追價風險，即使基本面良好。
* PEG 偏高且處於高位 → 建議觀望或等待回測。

---

#### 四、輸出要求

請分析目前投資組合健康度，針對各標的給出具體結論。使用明確、可執行的語氣，不要只給模糊評論。

輸出格式：

1. **投資組合健康度總結** — 整體配置、現金水位、區域占比、主動/被動比例、集中度風險
2. **今日決策摘要** — 是否適合加碼、優先標的、建議子彈數、是否違反配置目標、等待條件
3. **各標的長線建議** — 加碼 / 觀望 / 暫停加碼 / 降低優先度，附理由（不要建議賣出）
4. **各標的短線建議** — 日常 / 回測 / 狙擊 / 觀望；現價 vs 掛單位階；FOMO / 追價風險
5. **配置風險檢查** — 各區域 / 類型占比是否合理，是否違反配置目標
6. **最終行動建議** — 優先標的與子彈數，明確可執行
