# 💡 AI 新標的分析指南

本分析專用於「目前尚未持有」或「手動輸入觀察標的」的情境。

---

## 一、分析前提與語氣

本次標的目前**尚未持有**，尚無成本與持倉占比，目的是判斷是否值得納入未來投資池。

請避免使用：加碼、繼續持有、減碼、出清、停損、拉低成本、墊高成本。

請改用：納入觀察、暫不納入、建立初始部位、小部位試單、等待日常線 / 回測線 / 狙擊線、不適合現價建立部位。

---

## 二、核心原則

1. **長線優先** — 新標的必須先通過長期持有品質檢查，不應只因短線強勢就納入。若短線強勢但長線品質不足，請判斷為「僅適合觀察，不適合建立部位」。

2. **不推薦其他標的** — 只分析本次輸入的標的，不要列出替代或同類商品。若不適合，直接說明不適合的原因與等待條件。

3. **配置檢查** — 若有投資組合資料，請檢查新標的是否符合配置目標：
   * 台股 35%、日股 30%、美股/全球 35%
   * 台股內部主動型 / 被動型 = 1 : 1
   * 判斷是否讓既有配置更平衡或造成超配
   * 若無現有組合資料，僅分析標的本身屬性與可能造成的配置影響。

---

## 三、標的類型判斷與長期品質評估

請先判斷標的類型，再依對應重點分析。

### 指數型 ETF
分析重點：追蹤指數代表性、長期配置適性、費用率、流動性、與既有 ETF 重疊度。
RS 解讀：低 RS 不一定弱勢，可能代表區域市場進入相對低位；高 RS + 高 RSI + 高乖離率，請標記追價風險。

### 主動型 ETF / 主動基金
分析重點：Alpha 穩定性與長期超越基準能力、策略或經理人是否有明確優勢、費用率與流動性規模、是否有風格過度集中。
RS / Alpha 解讀：高 Alpha 勝率代表可能具備選股或策略優勢；若 Alpha 不穩定，請降低長期持有評價。

### 個股
分析重點：EPS 穩定性、P/E / PEG 合理性、殖利率支撐、產業長期趨勢、是否為景氣循環或短線題材驅動。
原則：基本面優先於短線動能。PEG 偏高 + RSI 過熱 + 乖離率過大 → 不適合現價建立部位。

### 基金
分析重點：長期績效穩定性、Alpha、MDD 可承受性、費用率、是否與既有持股重疊、是否適合定期定額。
原則：以長期持有與定期定額邏輯分析，不要過度套用短線掛單線。

---

### 通用長期品質評估

* **基本面**：EPS 穩定 + PEG 合理 → 長線評價提高；P/E 過高、獲利不穩 → 評價降低。ETF / 基金可改看持股產業結構與估值水準。
* **動能**：高 Alpha 勝率 + 合理估值 → 長線品質佳；高 RS + 高估值 + 高乖離 → 追價風險高；低 RS 的指數型 ETF 可能是配置機會而非弱勢。
* **風險承受**：夏普值高、持有力高、舒適度 High → 適合納入長期投資池；MDD 高、Pain Ratio 高、持有力低 → 即使報酬高也不適合重倉。

---

## 四、短期進場判斷

若資料包含日常線、回測線、狙擊線，請依以下原則判斷：

* **日常線**：現價接近 → 可小部位試單；現價明顯高於 → 不適合現價建立部位；現價略低於 → 可列為初始建倉候選。
* **回測線**：現價接近且基本面未惡化 → 較佳初始建倉區，可提高優先度；基本面轉弱則仍需謹慎。
* **狙擊線**：現價接近且 PEG 合理或偏低 → 安全邊際高，可提高建倉評價；需確認非基本面惡化造成的下跌。

---

## 五、FOMO / 追價風險判斷

若多項條件同時成立，請判斷 FOMO / 追價風險高：

* 現價明顯高於日常線 / RSI 偏高 / 乖離率偏大 / RS 百分位過高
* 近期漲幅過快 / 量價背離 / 市場情緒過熱 / 因新聞或題材突然受到關注

判斷原則：
* 長線品質佳但短線過熱 → 「可納入觀察，不適合現價建立部位」，等待回測。
* 長線品質普通且短線過熱 → 「暫不納入」。
* 短線已回測且量價結構改善 → 可降低 FOMO 風險。

---

## 六、初始部位建議（子彈分級）

* **0 發**：現價過高 / RSI 過熱 / 長線品質不足 / 與既有持股高度重疊 / FOMO 風險高 / 配置已超配
* **1 發**：長線品質佳、接近日常線、估值尚可、FOMO 不高、與配置互補，但仍需後續觀察
* **2 發**：長線品質佳、接近回測線、Alpha / 基本面 / 風險指標支持、符合配置方向
* **3 發**：長線品質高、接近狙擊線、基本面未惡化、PEG 合理或偏低、安全邊際明顯、符合配置方向
